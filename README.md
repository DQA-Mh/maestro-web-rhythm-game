# Maestro, Nhạc Trưởng

A browser rhythm game built with Vanilla HTML, CSS, Canvas 2D, Web Audio API, and MediaPipe Tasks Vision.

## Run locally

`python3 -m http.server 4173`, then open `http://localhost:4173` in Chrome or Edge. Webcam access requires localhost or HTTPS. If the camera is unavailable, use the mouse fallback.

## Controls

Mouse or hand wrist moves the baton. Click or tap conducts. A/D pans the opera scene. Enter starts from the menu.

## Notes

The demo soundtrack is generated with Web Audio API, so the repository stays asset-light. Replace it with a licensed or public-domain recording later. Scene art is Canvas placeholder geometry and can be swapped for sprite sheets without changing gameplay.
